# Nowa Music サイト v2 デザイン刷新 設計書

作成日: 2026-08-12
対象: https://nowajp.com（既存の Astro サイト）
参照: Codex制作仕様書「Nowa Music 公式Webサイト v2」、および Codex 版 HOME のスクリーンショット

## 1. 目的

公開中のサイトの見た目を、Codex 版スクリーンショットの水準まで引き上げる。
「YouTubeチャンネルの案内ページ」ではなく「ひとつの音楽ブランドの公式サイト」に見えることを目指す。

参照仕様書は STORIES（恋物語）と感情セレクターという新機能も含むが、**今回はデザインのみを対象とする**。新機能はオーナーが物語の文章と楽曲への感情タグを用意できた段階で、別の設計として扱う。

### 成功の基準

- 初見の人が「AIで作った音楽サイト」ではなく「ひとつの音楽ブランド」と感じる
- スクロールしても第一印象の質が落ちない（ヒーローだけ豪華で下が安っぽい、という状態にしない）
- 375px で横スクロールが出ない
- 既存の機能（YouTube日次自動更新・サイト内プレイヤー・画像最適化・独自ドメイン）が一切壊れない

## 2. 変えないもの

| 項目 | 理由 |
|---|---|
| Astro + GitHub Pages + nowajp.com | 稼働中。Next.js/Vercel へ移す利点がなく、費用と複雑さだけ増える |
| YouTube日次自動更新（Actions） | 正常稼働中。触る理由がない |
| サイト内プレイヤー（`Player.astro`）と `data-play` 契約 | 実機で動作確認済み |
| 画像の webp 自動最適化（`getImage`） | ヒーロー 1.26MB→49KB 等の実績 |
| 配色（深い藍・月光の青・アイボリー） | 世界観の核。変更しない |
| 既存のテスト29件 | 全て維持する |
| ページ構成（`/`・`/music`・`/about`） | 増減させない |

## 3. デザインの言語

### 3.1 書体

欧文用の表示書体を1本追加し、和文は現状を維持する。この2本立てが「上質さ」の実体である。

| 用途 | 書体 | 備考 |
|---|---|---|
| 欧文の見出し・ラベル（NOWA MUSIC / ALBUM / LISTEN 等） | Cormorant Garamond 300・400 | Google Fonts。ラテン文字のみ読み込まれるため追加は約20KB |
| 和文すべて | Noto Serif JP 200・300・400 | 現行のまま |

CSS変数 `--font-display` を追加し、欧文見出しに適用する。和文は既存の `--font-serif` を使い続ける。

### 3.2 文字の大きさ

現行は全体に控えめすぎる。以下へ引き上げる。

| 要素 | 現行 | 変更後 |
|---|---|---|
| ヒーローのブランド名 | （なし） | `clamp(2.75rem, 11vw, 8rem)` / weight 300 |
| ページ見出し（MUSIC・ABOUT の h1） | `clamp(1.35rem, 4.5vw, 1.9rem)` | `clamp(2rem, 6vw, 3.5rem)` |
| セクション見出し（h2） | `clamp(1.35rem, 4.5vw, 1.9rem)` | `clamp(1.5rem, 5vw, 2.4rem)` |
| セクションラベル | 0.7rem / 字間 0.34em | 変更なし（書体のみ `--font-display` へ） |
| 本文 | 変更なし | 変更なし |

### 3.3 罫線

細い線（既存の `--line`）を設計要素として使う。ヘッダー下、セクション見出しの下、ボタンの枠、プロフィール情報の行間に通し、誌面のような骨格を与える。

## 4. ヘッダー

全ページ共通。上部に固定し、スクロールしても残る。

```
NOWA                       MUSIC  ABOUT   [ LISTEN ↗ ]
MUSIC
─────────────────────────────────────────────────────
```

- 左: 2段組みロゴ。`NOWA`（`--font-display` / 字間 0.3em）の下に `MUSIC`（0.6rem / 字間 0.4em）
- 右: ナビ `MUSIC` `ABOUT`、続いて枠付きの `LISTEN ↗`
- 下端に 1px の罫線、背景は半透明＋わずかなぼかし（`backdrop-filter`）
- 現在地のナビ項目は `aria-current="page"` とアクセント色（現行の挙動を維持）
- **STORIES はナビに入れない**（作らないため）
- `LISTEN` の遷移先は `/#listen`。どのページからでもトップの「聴けるところ」へ着地する

**位置指定の変更に伴う2点**:

1. 現行ヘッダーは `position: absolute`。固定化に伴い、`/music`・`/about` の冒頭余白（`.head` の `padding-top`）がヘッダーに隠れないことを確認する
2. アンカー遷移（`/#listen`）の着地点が固定ヘッダーの下に潜らないよう、id を持つセクションに `scroll-margin-top` をヘッダーの高さ分だけ与える。トップの既存 id は `albums` / `about` / `listen` の3つ

半透明の背景色は新しいCSS変数として定義する（色の直書きは禁止）。

## 5. ヒーロー（トップ）

```
A J-POP BALLAD PROJECT

NOWA MUSIC              ← 巨大な欧文明朝

眠れない夜に、
ひとつの恋の物語を。

┌────────────────┐
│ 今夜の1枚を聴く  → │
└────────────────┘

              SCROLL              TOKYO · NIGHT · 00:17
                │                    （右端・縦書き）
```

| 要素 | 内容 |
|---|---|
| 上部ラベル | `A J-POP BALLAD PROJECT` |
| ブランド名 | `NOWA MUSIC`（`--font-display`、ページの h1） |
| 日本語コピー | 「眠れない夜に、」「ひとつの恋の物語を。」の2行 |
| CTA | 角ばった枠＋矢印。文言は「今夜の1枚を聴く →」。最新アルバムを再生（現行の `data-play` 契約をそのまま使う） |
| SCROLL誘導 | 下部中央。`SCROLL` の文字と 1px の縦線。全画面幅で表示 |
| 縦書きの時刻 | 右端に `TOKYO · NIGHT · HH:MM`。**768px以上のみ表示**（スマホでは幅を圧迫するため） |

時刻は閲覧者の現在時刻を表示し、1分ごとに更新する。`TOKYO · NIGHT` は静的に出力し、時刻部分だけをスクリプトで埋める。JavaScript が動かない環境では時刻が出ないだけで、レイアウトは崩れない。

CTA は現行の丸いピルから角ばった枠に変更する。アルバムしか載せていないため文言は「1枚」で統一する。

## 6. セクション見出しの型

トップ・MUSIC・ABOUT のすべてで、次の3点セットを繰り返す。

```
ALBUM                  ← 小さな欧文ラベル
──────────────         ← 細い罫線
眠りにつくまでの時間に、そっと。   ← 大きな和文見出し
```

既存の `.section__label` / `.section__title` を拡張し、間に罫線を挟む形にする。罫線は装飾要素であり、スクリーンリーダーには読ませない。

## 7. トップの各セクション

| セクション | 変更内容 |
|---|---|
| 世界観の3行 | 文字を一段大きくし、前後の余白を広げる。スクロールで順に浮かぶ動きは維持 |
| アルバム棚 | PC（64rem以上）で**3列**に変更。サムネイルに細い枠。タイトルを `--font-serif` のまま一段大きく。**公開年**を小さく添える |
| Nowaについて | 見出しの型を適用。本文は現行のまま |
| 聴けるところ | 文字リンクの横並びから、**罫線で囲んだ一覧**へ変更。各項目に `↗` を添える |

アルバムカードのタッチ端末対応（▶ が常に薄く見える `@media (hover: hover)` の切り分け）は現行の実装を維持する。公開年は `Album.publishedAt` から表示側で算出し、`catalog.js` は変更しない。

## 8. MUSIC と ABOUT

**MUSIC**

- 冒頭を新しい見出しの型に（`MUSIC` ＋ 罫線 ＋「夜のための、アルバム。」）
- アルバム55件はトップと同じ新カードで表示
- 末尾の「もっと聴く（YouTubeチャンネル）」は位置・文言とも維持

**ABOUT**

- 冒頭を新しい見出しの型に
- 写真と本文の2段組みは維持
- プロフィール情報（`dl.facts`）を**罫線で区切った定義リスト**として整える。項目名は控えめに、値を主として見せる

## 9. レスポンシブ

| 幅 | 要件 |
|---|---|
| 375px | 横スクロールなし。ブランド名は必要なら折り返す。縦書きの時刻は非表示。ヘッダーは高さを詰める |
| 768px | 縦書きの時刻を表示開始。アルバムは2列 |
| 1280px | アルバム3列。ヒーローは横長画像 |
| 1920px | 余白が間延びしないよう、本文の最大幅を維持 |

## 10. 守る制約

- 言語は日本語のみ。UI文言・コメント・コミットメッセージも日本語
- **色は CSS変数のみ**。新しい色が必要なら `theme.css` の `:root` に変数を追加してから参照する
- 外部依存は Astro のみ。UIライブラリ・アニメーションライブラリを追加しない
- 動きは fade in / fade up まで。派手な動きは入れない（`prefers-reduced-motion` の尊重も維持）
- テスト29件を維持

## 11. 進め方と検証

公開中のサイトを壊さないため、次の順で進める。

1. **`v2-design` ブランチで作業する。`main` には触らない**。作業中も nowajp.com は現行のまま動く
2. 各段階でローカルビルドし、**375 / 768 / 1280 / 1920px のスクリーンショット**をオーナーに提示する
3. `npm test`（29件）と `npm run build` が通ることを各段階で確認する
4. オーナーの承認後に `main` へ統合して公開する。承認されなければブランチを破棄するだけで、現行サイトは無傷

### 検証項目

- 4つの画面幅で横スクロールが発生しないこと
- ヘッダー固定後、`/music`・`/about` の冒頭がヘッダーに隠れないこと
- アルバム・CTA のクリックでプレイヤーが開き、Escape で閉じ、音が止まること（`data-play` 契約の維持）
- `LISTEN` からトップの「聴けるところ」へ着地すること
- 縦書きの時刻が 768px 以上で表示され、375px で消えること
- 欧文書体の読み込み失敗時も和文書体にフォールバックしてレイアウトが崩れないこと

## 12. 今回作らないもの

- STORIES（恋物語）と STORY DETAIL ページ
- 感情セレクター「今夜はどんな気持ちですか？」
- PLAYLISTS の独立セクション
- Next.js / Vercel への移行
- ハンバーガーメニュー（ナビが2項目のため不要）

STORIES と感情セレクターは、オーナーが物語の文章と楽曲ごとの感情タグを用意できた時点で、別の設計として着手する。今回のデザインはその追加を妨げない構造にしておく。
