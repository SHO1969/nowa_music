# Googleアナリティクス（GA4）導入 設計書

作成日: 2026-08-13
対象: https://nowajp.com（公開中の Astro サイト）

## 1. 目的

サイトの閲覧状況を把握する。具体的には、何人が来たか、どのページが見られたか、どこから来たか（YouTubeの概要欄・SNS・検索）、スマホかPCか。

計測対象は**ページの閲覧状況のみ**とする。アルバム再生などの独自イベントは今回作らない。

### 成功の基準

- デプロイ後、GA4のリアルタイム画面に自分のアクセスが表示される
- ローカルでのプレビュー・開発時のアクセスが数字に混ざらない
- 表示速度が体感で落ちない
- 既存の機能（プレイヤー・自動更新・画像最適化）が壊れない

## 2. 前提

| 項目 | 内容 |
|---|---|
| 測定ID | `G-1TMW24TDHY` |
| ストリームID | 15447415618 |
| 拡張計測機能 | 有効（GA4側の設定）。ページビューに加え、スクロール深度と外部リンクのクリックがサイト側の実装なしで記録される |
| プロパティ | Nowa Music / タイムゾーン日本 |

**測定IDは秘密情報ではない。** ブラウザ側のコードに必ず出力されるものであり、リポジトリが公開でもそのまま記載してよい。APIキーとは性質が異なるため、GitHub Secrets や `.env` では扱わない。

## 3. 構成

既存の `src/lib/links.js` と同じ考え方で、設定値を1箇所に集める。

| ファイル | 役割 |
|---|---|
| `src/lib/analytics.js`（新規） | 測定IDの定数と、計測を出力すべきかの判定を持つ |
| `src/layouts/BaseLayout.astro` | `<head>` に計測タグを出力する（条件付き） |
| `src/components/Footer.astro` | 利用告知の一文を表示する |

### 3.1 出力条件

計測タグを出力するのは、次の**両方**を満たすときだけとする。

1. 測定IDが空文字でないこと
2. 本番ビルドであること（`import.meta.env.PROD` が真）

1つ目は `links.js` で「URLが空なら表示しない」としたのと同じ考え方で、IDを空にすれば計測を止められる。2つ目は、ローカルのプレビュー確認で自分のアクセスが数字に混ざるのを防ぐため。

### 3.2 計測タグ

Googleが提示する標準のスニペットをそのまま使う。

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-1TMW24TDHY"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-1TMW24TDHY');
</script>
```

測定IDは `analytics.js` の定数から埋め込み、タグ内に直書きしない。

`<head>` 内の位置は、既存の書体読み込み（`fonts.googleapis.com`）より**後ろ**に置く。書体は見た目に直結するため先に読ませ、計測は `async` で後追いさせる。

### 3.3 利用告知

`Footer.astro` のコピーライト表記の近くに、次の一文を小さく添える。

> 当サイトではGoogleアナリティクスを使用しています。

文字色は `--text-dim`、大きさはコピーライト行と同等かそれ以下。世界観を損なわないよう控えめにする。外部リンクは張らない。

## 4. 速度への影響

`gtag.js` は約50KB。`async` で読み込むため、ページの表示開始を止めることはない。

軽量化のための追加ライブラリ（Partytown 等）は導入しない。依存を増やさない方針を維持する。

## 5. 守る制約

- 言語は日本語のみ。UI文言・コメント・コミットメッセージも日本語
- 色は `theme.css` の CSS変数のみ
- 外部依存（npmパッケージ）を追加しない
- 既存の29テストを維持する
- `src/lib/catalog.js`・`src/lib/embed.js`・`scripts/`・`src/components/Player.astro`・`src/data/youtube.json`・`.github/workflows/` は変更しない
- スマホ優先。375px で横スクロールを発生させない

## 6. 検証

- ビルドした `dist/index.html`・`dist/music/index.html`・`dist/about/index.html` の3ページすべてに測定IDが含まれること
- `analytics.js` の測定IDを一時的に空にすると、3ページとも計測タグが消えること
- フッターの一文が3ページとも表示され、375px で崩れないこと
- `npm test` が29件パスし、`npm run build` が警告なく成功すること
- デプロイ後、`https://nowajp.com` にアクセスしてGA4のリアルタイム画面に反映されること

## 7. 今回やらないこと

- クッキー同意バナー（日本国内向けの個人サイトのため）
- プライバシーポリシーの独立ページ（フッターの一文で代える）
- アルバム再生を記録する独自イベント
- 配信リンクのクリックを記録する独自イベント（GA4の拡張計測機能が自動で拾うため不要）
- Partytown 等による計測タグの軽量化
- 自分のアクセスを除外するIPフィルタ（必要になればGA4側の設定で行う）
